Run Forge

One instruction. Bounded first contact.

Put Forge beside the complete working project, run from the project root, and read .forge/resume.md before editing.

Start

python3 Emotivus-Forge/forge.py

Windows fallback:

Emotivus-Forge\forge.cmd

Safe automatic behavior

  • Not adopted: Progressive Adopt + Resume.
  • Adopted and unchanged: Resume.
  • Adopted with changed files: scoped Check + Resume.

What to copy next

Run Forge prints one bounded line in the form Forge recommends this prompt — …. Copy it into the active AI conversation. A blocker or unconfirmed objective produces a stop-before-code prompt rather than a continuation instruction.

Never automatic

  • Native gate execution without approval.
  • Ship, deployment, deletion, production migration, or environment repair.
  • Any advanced capability activation or execution without a current project-owned contract.
  • Graph, legacy Lab, expanded Evidence, CI, update, remediation, or any vault activation.
  • Runtime Proof execution without a current project-owned contract and explicit Check request.
  • Runtime-state confirmation without current identity, matrix authority, supplied owner/CI testimony, and same-Check recipes.
Current boundary: Ship is always explicit. A Scoped Check PASS is not browser evidence, database-data, deployment execution, rollback, production, release authorization, or release proof. Browser viewport evidence is a separate exact-package instrument with narrower truth boundaries. Bounded release-ready requires the complete cumulative ladder and a separate exact-package authorization.
