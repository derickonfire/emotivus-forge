# Forge 0.548 final-recommendation audit

## Decision

The recommendation is useful and directionally important, but it is not accepted wholesale. Its central discipline—prefer durable truth over model-compensation ceremony, score real catches, and define a stop-loss—is adopted as roadmap advice. Load-bearing implementation claims were checked against the exact sealed 0.548 package before code changes.

## Verified status table

| Recommendation claim | Verified 0.548 status | Decision |
|---|---|---|
| Unbaselined tree can receive PASS | **Confirmed.** Direct `forge check --json` returned `PASS` while `authority_baseline.status` was `NOT_ESTABLISHED`. | Fix first in 0.549. |
| Every blocker names a resolving artifact or command | **Not generally true.** Many findings contain only `check`, `path`, `line`, and `message`; some higher-level objects provide next actions. | Keep as a future mechanical usability task. |
| No-argument five-state routing is not built | **False.** `core.startup.run_forge` implements three executable routes and blockers/needs-project states. | No rebuild of existing routing. |
| `forge close` is not built | **True as phrased.** Session Close exists under Check with many flags. | Do not add a sixth public command; evaluate a file-backed Check wrapper. |
| Structural CSS/JSON/merge checks exist | **Confirmed in code and regressions.** The claimed real-project catch remains external testimony until scored against preserved ground truth. | Keep. |
| Graph node inventory is working | **Vault implementation exists.** It is not active-core certified in 0.548. The external trial result is testimony. | Recertify only after a scored trigger. |
| Graph impact is reliable | **Not established.** The vault implementation is static and dynamic PHP include behavior is not certified. | Never present as general runtime impact. |
| Browser evidence was never run | **False.** The exact 0.548 browser bundle re-verifies against the delivered website digest. | Keep exact static-package rendering; server-rendered/origin capture remains open. |
| Session Close generates useful Resume data | **Implementation confirmed; comparative quality remains testimony.** | Keep. |
| Portable continuity export is package-bound | **Confirmed in implementation and regressions.** | Keep. |
| Release Proof is uncertified | **False.** It is active-core, tested, and Ship-integrated as a bounded assurance-map validator. | Keep unless later field evidence shows net harm. |
| Two of nine capabilities have implementations | **Misleading.** Doctor and Runtime Proof are activatable; Release Proof is integrated core; Graph has frozen executable legacy code. Other catalog entries are vaulted/deferred. | Report exact states, not one count. |
| `OBSERVED` benchmark tier exists | **False; it is absent.** Controlled benchmark entries require exact provider token counts. | Candidate after 0.549 truth correction. |
| Six-defect scoreboard has been run | **Not supported.** The recommendation supplies a judgement table, not an admissible scored observation bundle. | Do not enter it into the ledger. |
| Seven-goal 89% proves efficacy | **False.** It is implementation-progress arithmetic, not defect-detection evidence. | Stop using it as an efficacy signal; design scored reporting after a real trial. |
| Capability contracts should be deleted | **Not established.** They currently provide material safety boundaries beyond prose ceremony. | Reject wholesale deletion; measure concrete friction first. |
| Active docs are oversized | **Confirmed:** 62 Markdown documentation files, approximately 22,658 words. | Map dependencies before moving material to reference. |

## Accepted product direction

1. Cross-vendor, package-bound continuity and deterministic evidence are durable value.
2. Guidance prose and ceremony must justify themselves against native platform features.
3. Forge needs an obtainable observed benchmark tier and a scored defect table.
4. The seven-axis percentage must not substitute for efficacy evidence.
5. A stop-loss should govern capability expansion after one scored trial.

## 0.549 boundary

Only the unbaselined aggregate truth-state defect is corrected in this build. This keeps the change reactive, directly observed, and small enough to certify independently. The recommendation's broader scope cut remains roadmap advice pending scored evidence.
