# Forge 0.556 (in development) — the trustworthy context digest

Bounded implementation of the observed miss recorded in
`OBSERVED-MISS-project-intelligence.md` and the 12-project spectrum test
(`SPECTRUM-TEST-12-PROJECTS.md`). Turns the first-contact Brief from labels-plus-
ceremony into a compact, trustworthy digest — which is also the token-conservation
feature, because you cannot conserve tokens with a Brief the model can't rely on.

Development on top of sealed 0.555; **not yet sealed**. All 523 regressions across
54 modules stay green; every change is additive (no field or line removed, no
passport/resume checksum affected).

## Landed increments

### A · Secret screening now fires at first contact *(headline defect fixed)*
`confidentiality_boundary.classify_confidentiality_boundaries` gained a bounded
full-text pass (≤400 files, ≤1 MB each) that content-scans every text file via the
existing `secret_screening.screen_text` — not only files flagged by filename. The
`.env`-shape catch is retained; hardcoded secrets in ordinary source are now caught.
- **Proof (vibe-slop):** the planted `OPENAI_API_KEY = "sk-proj-…"` in `app.py`,
  previously missed entirely (`files_examined:0`), now returns
  `BLOCK / blocked:true`, `app.py` flagged as a boundary candidate, value not
  retained. `mode` moves from `metadata-only` to `bounded-content`.

### B · First-contact orientation + identity fallback
New deterministic `orientation.derive_orientation()` reads, bounded, from the
project itself: a one-line **description** (README prose or manifest), **entry
points**, and **run/test commands** (npm scripts, python entry + pytest, `go
run/test`, `cargo run/test`, artisan/phpunit, static site). `_read_project_name`
now falls back through **go.mod → Cargo.toml → README H1 → directory** instead of
directory-name-only.
- **Proof:** `hey` (Go) is now named **"hey"** (from go.mod, was "proj") with
  "hey is a tiny program that sends some load to a web application", `go run/test`.
  Flask now reads "Flask is a lightweight [WSGI] web application framework…",
  `python app.py` / `pytest`.

### C · Measured token economics
`resume.py` adds a **Context economics** line comparing the Resume's token cost to
reading the whole project (`current_snapshot.total_bytes / 4`), deterministic via
the existing placeholder-substitution idiom.
- **Proof:** Flask Resume ≈ 1,056 tokens vs ≈ 467,497 to read the repo —
  **~443× lighter**. The 3-file vibe-slop app honestly reports **~2× heavier —
  overhead exceeds the read at this size**. The saving is real on large/repeated
  projects and honestly negative on tiny ones.

### Terminal Brief now leads with the digest
The `FORGE STARTED` block surfaces `What it is` / `How to run` / a `Secrets: N
BLOCK · M REVIEW` alert right after the project name — the first thing a cold model
or a vibe coder sees.

### D · Lazy governance (done)
The resume compact digest now omits the empty base governance lines (Project
identity, Lineage, Migration identity, Package family, Final release package) when
a project has not declared them. Flask resume dropped from ~1,056 to ~981 tokens
with zero `NOT_DECLARED` lines; they reappear the moment a project declares them.

### E · Orient before blocking (done)
A missing objective is now a **warning** on a clean read-only first contact and a
**blocker** only once there are changes to govern. The recommended prompt for a
no-objective project is orientation-forward ("Orient and read the project freely
first…") instead of "Stop before changing the project."

## Spectrum re-test (12 projects, measured lift)

| Metric | Before (0.555) | After (0.556) |
|---|---:|---:|
| Mean cold-model usefulness | 1.83 / 5 | **2.67 / 5** |
| Blocked before value | 11 / 12 | **0 / 12** |
| Architecture ≥ partial | 0 / 12 | 5 / 12 |
| Vibe-coder app (target user) | 1 / 5 | **4 / 5** |
| Hardcoded key caught | missed | **BLOCK** |

The re-test also surfaced three defects in the new code, now fixed: a hallucinated
`src/index.js` entry point (now exact relative-path membership only), `cargo run`
recommended for a library-only crate (now `cargo build` unless `src/main.rs`
exists), and badge/kaomoji README lines used as descriptions (now skipped for real
prose, with a Cargo.toml/pyproject description fallback).
