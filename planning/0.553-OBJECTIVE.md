# Forge 0.553 objective

Reorganize and re-point Forge for the 2029 horizon **before** resuming core
reduction, without mutating the certified 0.552 record.

0.553 inherits a healthy 0.552: runtime confirmed working, all 523 regressions
passing across 54 isolated modules, 88 runtime modules with zero unreachable and
zero unclassified. The strategic decision for the next three years is recorded in
`../FORGE-2029-VERDICT.md` (verdict: **save and sharpen**) and the forward plan in
`../ROADMAP-2029.md`.

## In scope for 0.553

1. **Stage the direction, don't fake the release.** The 2029 verdict and forward
   roadmap are added as new, classified top-level documents. The certified 0.552
   consistency surface (`FORGE-PRODUCT.json`, `FORGE-MANIFEST.json`, `CHANGELOG.md`,
   `PROGRESS-STATUS.md`, `ROADMAP.md`, `README.md`, `CERTIFICATION.md`) is left
   sealed until the version bump is done in one coherent, self-checked operation.

2. **Land the first real 0.553 code change (F-553-001):** the runtime reachability
   mapper now classifies version-control metadata (`.git/`, `.github/`,
   `.gitignore`, `.gitattributes`) instead of leaving it as an unclassified,
   REVIEW-disposition top-level path. Forge now lives under version control; its
   own truth map must account for that. Suite remains 523/523.

3. **Land Phase A chunk `P1-03` (REDUCE).** Investigation (F-553-004) disproved
   the assumption that relocating docs would desync the manifest: `docs/` is a
   path *prefix* everywhere it is referenced, so nesting historical documents
   under `docs/history/` is zero-coupling. P1-03 is therefore executed in 0.553 —
   four zero-reference, historical/explanatory-only documents moved into
   `docs/history/` with no lost history — and the active chunk advances to P1-04.

4. **Record the Phase B miss.** Agent-native invocation (Run Forge as an
   agent/MCP-callable tool) is the highest-leverage future-proofing move. Per the
   expansion rule it may not be built until an observed miss is recorded — so
   0.553 records the miss and the ground-truth target, and builds nothing yet.

## Out of scope for 0.553

- Deleting any module (no fold is complete yet; reachability is not deletion
  authority — F-552-004 stands).
- Shipping the agent/MCP surface.
- Any change that would upgrade a `NOT_RUN` to `PASS` or claim release readiness.

## Boundary preserved

Forge supplies verified context and continuity; the model owns reasoning and
implementation. Nothing in 0.553 moves Forge toward being a coding agent or prompt
governor.
