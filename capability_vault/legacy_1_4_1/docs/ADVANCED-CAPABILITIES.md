# Advanced Forge Capabilities

The normal Forge product journey is:

```text
Adopt → Resume → Check → Ship
```

The following engines remain available for advanced diagnosis, configuration, and compatibility. They are not separate product concepts a normal user must learn first.

## Inventory and environment

- `understand graph`
- `understand doctor`
- `detect`
- provenance and source-completeness reports
- runtime requirement inference

## Durable project memory

- `understand ledger`
- `change plan`
- `change pivot`
- `understand context`
- `change learn`
- `change guardrail`

## Assurance and evidence

- `prove gate`
- `prove coverage`
- `prove lab`
- `prove evidence`
- runtime contracts
- release claim inspection

## Delivery and maintenance

- `prove deliver`
- `state`
- `update`
- `prove confidentiality`
- `prove mirror`
- CI bridge generation
- tool-ecosystem adoption and quarantine

Compatibility commands remain callable in 1.4.x so existing projects and scripts are not broken. They are intentionally omitted from normal `forge --help` output.
