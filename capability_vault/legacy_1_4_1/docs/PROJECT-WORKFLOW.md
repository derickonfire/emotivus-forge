# Adopt, Resume, Check, Ship

## Adopt

Create or refresh the Project Passport before substantial work begins. Adoption inventories the project, records uncertainty, establishes a file checkpoint, and preserves existing tools without automatically deleting or flattening them.

## Resume

Resume from the Passport rather than from conversational memory alone. The Resume packet contains the minimum sufficient verified context for the active objective.

## Check

Check after meaningful edits. Forge identifies changed paths, calculates graph impact, runs the requested proof profile, and advances the project observation only after recording the result.

## Ship

Ship only from a fresh Release boundary. Forge must state the strongest supported claim, preserve limitations, run confidentiality checks, and bind the generated ZIP to its proof.

## Advanced engines

Graph, Ledger, Context, Plan, Impact, Pivot, Learn, Guardrail, Gate, Lab, Evidence, runtime contracts, confidentiality, delivery, Mirror, CI, and tool continuity remain underneath this workflow.
