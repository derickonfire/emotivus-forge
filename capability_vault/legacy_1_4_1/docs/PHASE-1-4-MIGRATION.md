# Forge Core Phases 1–4

## Phase 1 — Neutral reusable core

Forge Core contains reusable auditing, release, packaging, reporting, and regression infrastructure with no project-specific content.

## Phase 2 — Initial configuration

Initialization detects the stack, records project decisions, creates a baseline policy, produces live-verification checklists, and establishes a project contract.

## Phase 3 — Stack adapters

PHP, JavaScript, CSS, Apache/cPanel, Node.js, and Python adapters activate built-in checks and provide an extension point for specialized commands.

## Phase 4 — AI-agent workflow

Forge generates a durable agent contract, machine-readable reports, plain-text evidence, resumable checks, and explicit rules against weakening gates or silently expanding baselines.

## v1.0.1 extension

The initial run now audits existing development and release tools, can absorb safe commands, and can reversibly quarantine narrow confirmed duplicates. Human web documentation is bundled with the portable distribution.
