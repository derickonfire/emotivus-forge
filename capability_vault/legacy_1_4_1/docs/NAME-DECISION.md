# Name Decision

## Recommended name: Emotivus Forge

“Forge” communicates both construction and hardening. The platform does more than supply tools: it establishes a project contract, tests code and policy, preserves defect knowledge, controls release identity, and produces deployment artifacts.

It also creates a clear command vocabulary:

- Forge Init
- Forge Audit
- Forge Quick
- Forge Section
- Forge Release
- Forge Package
- Forge Policy Pack

## Strong alternatives

- **Emotivus Sentinel** — stronger emphasis on monitoring and protection, but weaker on creation and packaging.
- **Emotivus Foundry** — broader platform feeling, but slightly less direct and command-friendly.
- **Emotivus Guardrail** — very descriptive for AI-assisted coding, but too narrow for initialization and release production.

For internal use, no trademark or domain-availability screening has been performed or is necessary. Conduct that review before any public product launch.
