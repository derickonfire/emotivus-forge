Goals 2 and 3

Continuity that can outlive today's models.

Forge carries exact project truth between sessions and vendors, then evolves only through observed misses, migrations, and scored trials.

G1

Provable Project Truth

COMPLETE

Forge identifies the exact project, authority, lineage, changes, evidence, and authorized package without asking an AI model to infer them.

G2

One-Command Session Continuity

ACTIVE

Run Forge determines whether the model is entering, resuming, checking, closing, or assessing a release candidate and returns compact verified context.

G3

Cross-Model Evolution Kernel

CONTINUOUS

Forge preserves vendor-neutral project truth and a scored evolution loop so newer models can simplify or extend Forge without erasing history.
